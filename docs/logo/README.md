# phi 标识

Menlo 的小写 φ 落在终端底色的圆角块上，右边一个光标方块。
版式是按 Menlo 自己的字体度量摆的：光标块坐在真实基线上，高度取自字母的 x-height，
所以缩放到任何尺寸，字和光标的关系都不会散。

| 文件 | 用在哪 |
|---|---|
| `phi-mark.svg` | 矢量原件。深色底版本，**优先用这个** |
| `phi-mark-light.svg` | 浅底版本（纸白块 + 墨色字），印刷或浅色版式里用 |
| `phi-mark-mono.svg` | 只有字形，无底，填充色是 `currentColor`，跟着上下文的文字颜色走 |
| `phi-512/256/128/64/32/16.png` | 位图，透明圆角。README 题图用 128 |
| `favicon.ico` | 16 / 32 / 48 三层，给以后的 web 端用 |
| `phi-social.png` | 1280×640，GitHub 仓库 Settings → Social preview 手动上传 |

PNG 是把矢量渲到 1024 再逐级 LANCZOS 缩下来的，不是各尺寸分别栅格化 ——
小尺寸下边缘更干净。改了 SVG 之后要重新生成整套，别只改一个。

颜色：底 `#12141a`，字 `#4fd1e0`。两个都取自 TUI 自己的配色。
